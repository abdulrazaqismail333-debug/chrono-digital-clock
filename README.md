# ⏰ Chrono Digital Clock

A responsive digital clock and time-management project built with HTML, CSS, and JavaScript.

## 🌐 Live Demo

[View Chrono Digital Clock](https://abdulrazaqismail333-debug.github.io/chrono-digital-clock/)

## ✨ Features

- Live digital clock
- Responsive user interface
- Clean, modern design
- Time-management tools

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🚀 Getting Started

1. Clone or download this repository.
2. Open `index.html` in your browser.
3. Enjoy Chrono Digital Clock!
